# 禁用詞與免責修飾語

「中文／英文禁用詞」與「免責修飾語」命中即改寫失敗。中文（繁、簡）用子字串比對。英文不分大小寫，比對整詞或列出的詞組。

本檔以繁體條目為主；簡體異體一併列出。檢查腳本讀本檔，不要在腳本裡另寫一份詞庫。

「宜避」一節只給改寫時參考，腳本不因此判失敗。

## 中文禁用詞

- 此外
- 值得注意的是
- 總而言之 / 总而言之
- 綜上所述 / 综上所述
- 不難發現 / 不难发现
- 正如…所言（亦含 正如X所言）
- 毋庸置疑
- 換言之 / 换言之
- 深入探討 / 深入探讨
- 賦能 / 赋能
- 畫卷 / 画卷
- 紐帶 / 纽带
- 雙刃劍 / 双刃剑
- 不可或缺
- 不言而喻

## 英文禁用詞

- delve
- tapestry
- furthermore
- in conclusion
- beacon
- nuanced
- interplay

## 中文免責修飾語

- 可能（勿誤傷「不可能」「可能性」）
- 在某種程度上 / 在某种程度上
- 或許 / 或许
- 值得討論的是 / 值得讨论的是

## 英文免責修飾語

- perhaps
- maybe
- to some extent
- it could be argued
- arguably
- possibly
- it is worth noting
- in a sense

## 宜避（腳本不判失敗）

文學與論文裡常見。改寫時少用套話用法，檢查腳本不因此失敗。

### 中文

- 重塑
- 基石
- 編織 / 编织

### 英文

- notably
- harness
- testify
